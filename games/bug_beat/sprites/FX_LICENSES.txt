BUG BEAT - 2D EFFECT SPRITESHEETS  (provenance + frame layouts)
================================================================================
Game: Bug Beat (glossy cartoon bug-smasher, HTML5 canvas).
Need: frame-animated VFX sheets (splat, poof, hit-spark, sparkle, dust),
      transparent PNG, license clean for commercial use + redistribution
      bundled in a web game.
Scout date: 2026-06-20.
Playback model: ctx.drawImage(sheet, col*fw, row*fh, fw, fh, dx,dy,dw,dh),
      stepping frames left-to-right, top-to-bottom on a timer.

All dimensions below were READ from the real PNGs with Python/PIL (not guessed).
Every grid was VISUALLY VERIFIED by overlaying gridlines and inspecting cells.
All files verified to start with the PNG signature (89 50 4E 47) and are RGBA
(true alpha) unless noted. Frame counts assume row-major order.

License legend (from game-asset-scout SKILL):
  SAFE-CC0 = public domain, ship freely, attribution optional.
  All assets below are CC0. None require attribution. None are NC/ND/IP.

sinestesia_blood_splat.png
  Role:     #1 JUICY SPLAT / goo / liquid burst (bug squash).
  Source:   https://opengameart.org/content/animations-blood-hit-and-both-d
  Direct:   https://opengameart.org/sites/default/files/1_128.png
  Author:   Sinestesia
  License:  CC0 (SAFE-CC0)
  Style:    Smooth painterly cartoon liquid (NOT pixel-art). Centered burst:
            a blob splits into flying droplets, then settles to a puddle ring.
  Sheet:    2048 x 2048 px, RGBA, transparent.
  Grid:     4 cols x 4 rows = 16 frames, each 512 x 512 px (exact divisor).
  Why pick: Frames are centered in-cell -> drop straight onto a squashed bug
            with one drawImage loop. 512px frames downscale crisply to any
            sprite size. Red, but recolors trivially to green/lime goo via a
            canvas hue shift or a globalCompositeOperation='source-atop' tint.
            16 frames is the easiest possible step loop.
